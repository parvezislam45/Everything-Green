Building this project, I will face multiple challenges across both the backend and frontend:

1. Initially, I may face issues with securing API routes because JWT tokens might not be validated properly.
2. The webhook API needs to validate incoming requests to prevent unauthorized access, but hashing the signature correctly could be challenging.
3. Handling authentication state (JWT token) and managing API calls in Next.js might be confusing at first.
4. The database may not connect properly, and sometimes, user data might not be saved correctly.
